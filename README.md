# 💰 Finance Calculator (React)

A modern financial calculator web app built with **React + Tailwind CSS**, designed to help users plan investments and loans with clear visual insights.

---

## 🚀 Live Demo

👉 https://Darshan-Shet.github.io/react-finance-calculator/

---

## ✨ Features

* 📈 **SIP Calculator**

  * Monthly investment growth
  * Compounding visualization

* 🏦 **EMI Calculator**

  * Monthly EMI calculation
  * Total interest & payment breakdown
  * Interactive donut chart

* 💼 **Lumpsum Calculator**

  * One-time investment projection

* 🎯 **Insights & Breakdown**

  * Invested vs Returns
  * Principal vs Interest
  * Real-time updates

---

## 🎨 UI Highlights

## ⚙️ Setup

```bash
git clone https://github.com/Darshan-Shet/react-finance-calculator.git
cd react-finance-calculator
npm install
npm run dev
```

---

## 📦 Build & Deploy

```bash
npm run build
npm run deploy
```
